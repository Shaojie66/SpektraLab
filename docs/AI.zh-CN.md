# AI 选片、构图、磨皮与精修

[English](AI.md) · **简体中文** · [返回 README](../README.zh-CN.md)

这些功能由本 fork 新增，上游 SpektraLab 的发行版里没有。

右侧参数栏有 **AI** 标签页。功能默认关闭：在 **设置 ▸ AI** 中开启，选择服务商并填写 API Key。
使用 OpenAI 兼容的 `/chat/completions` 服务时，填写基础地址和支持图片输入的模型；本地 Ollama
可使用 `http://localhost:11434/v1`，无需 Key。Anthropic Claude 默认使用 `claude-opus-5-5`，
也可选择 `claude-sonnet-5-5`、`claude-fable-5-1` 或 `claude-haiku-5-5`。

**AI 选片**先检查曝光：如果照片仍为默认设置（均衡自动测光、曝光补偿为 0），就用当前胶片
分别以均衡、中央、保护高光和保护阴影测光冲印小样，拼成小样表，让模型按场景选择。夜景、烟花、舞台和
逆光适合保护高光；雪地、海滩和大片明亮天空适合保护阴影。夜景用平均测光可能被拉成灰色，
使胶片比较失去意义。选择会写入照片，可用 **撤销 AI 修改**一并撤回；模型回答无法解析时
保留原设置。当前曝光不是默认值时也会保留，界面会显示是 AI 选择还是沿用用户设置。

之后用每款彩色胶片及其声明的相纸冲印小样（反转片走扫描），跳过 push 冲洗变体，
当前组合排第一，也可选择包含黑白胶片。小样均沿用照片当前曝光，其余统一使用中性设置：
滤色包求解为中性，不使用场景置位、颗粒、眩光或调色。视觉模型收到带编号的联系表，以及裁切、亮度、对比度、
色彩丰富度、偏色和宽容度覆盖比例等指标，返回 3–5 个选择及其分数和理由。点击 **应用**
相当于选好胶片和相纸后点击冲印。小样由独立引擎实例渲染，不影响画布、编辑和撤销历史；
M 系列 Mac 上实测 19 款胶片、768 px 小样约需 3 秒。

**AI 构图**用于推荐裁切。点击 **推荐构图**后，先用本机 macOS 的 Vision 框架在一张整幅小样上检测地平线倾斜、
视觉重心（显著区域）和人脸，全程本地、免费、不联网。然后按规则生成 8–12 个裁切候选：显著区域是主体（不超过画面 35%）时，主体放在三分点
或居中；区域更大时（风光、城市景观）视为场景，候选为各比例下最大的裁切、该裁切保留上部或下部（天空更多或前景更多）
以及保留左侧或右侧的版本，再加一个略收紧的居中裁切；常用比例跟随照片显示方向（横图：原比例、3:2、5:4、1:1、16:9；竖图：原比例、2:3、4:5、1:1、9:16）；
地平线倾斜超过 0.5° 时自动拉直；第 1 格永远是当前构图，作为对照。硬规则：不切人脸，主体的视觉重心区域至少保留 90%（场景为 60%），
裁切面积不小于原图 40%，高度相似的候选会去重。候选渲染成带编号的构图小样，模型只负责挑出最好的 3 个并给出理由，
不需要报坐标，因为视觉模型擅长比较图片，不擅长给出精确的矩形。缩略图和应用时用的是同一个裁切变换，所见即所得。
点击 **应用**按该方案裁切和拉直，之前做的 90° 旋转和翻转保持不变；**撤销 AI 修改**可一步恢复。
片边开启或半格拼接时暂不可用。本地 Ollama（例如 `gemma4:26b`）和 Claude 都可以使用。

**人像磨皮**在显影前标签页的 **人像** 一节：**磨皮**滑块 0–100，默认 0（关闭），松手后才生效，无需 API Key。
没有检测到人脸时滑块不可用并说明原因；开启 **不应用胶片模拟** 时滑块同样不可用，画布此时显示未经处理的照片，滑块下方写着“磨皮在胶片之前处理，关闭胶片模拟时不生效。”支持撤销。人脸关键点由本机 macOS 的 Vision 框架检测，全程本地、免费、不联网。
为了找到合影里的小脸，会在整张图和互相重叠的分块上分别找脸，再在每张脸放大后的裁切图上读取关键点；
实测约 25 人的合影能找到 19 张脸（只在整张图上找是 7 张），10 人的合影 8 张（只找整张图是 6 张）。大部分被挡住或转得很偏的脸找不到。
找到了脸、却读不出五官（眼睛、眉毛、嘴唇、鼻子）的，多半是脸太小、转得太偏或被遮挡，这个人不做磨皮，人像滑块下方那行字会写出有几张，例如“检测到 19 张人脸 · 另有 1 张看不清五官，不处理”。
最大的一张脸也不到照片长边的 5% 时（例如约 25 人的合影，1440 px，最大脸 3.4%），这行字还会加上“人脸都很小，磨皮效果有限”。AI 精修拿到的也是这两条信息。
遮罩覆盖脸部轮廓并补上额头，挖掉眼睛、眉毛和嘴唇让五官保持清晰，边缘往内收并羽化，不碰发际线和背景；
脖子和身体皮肤不处理。做法是去掉中间尺度的斑驳和不均匀，保留更粗的面部明暗结构，默认也保留更细的毛孔纹理；磨掉多少取决于它相对周围皮肤的幅度：斑驳、痘印和泛红（约为皮肤亮度的 10–20%）会被磨掉，达到 50% 以上的起伏（如鼻梁、鼻梁旁的阴影、鼻翼的转折）属于脸的形体，予以保留，介于两者之间的磨掉一部分，所以鼻子和脸的其余部分一起磨，形体照样保留；
每张脸按自己的大小计算磨皮尺度，所以合影里后排的小脸不会被磨过头；
明显的线条（眼镜框、发丝）及其两侧会受保护，不被磨软，毛孔这类细纹理不受这条保护的影响。
皮肤上比周围暗得多或亮得多的东西（亮度不到周围的三分之一，或接近两倍）会被当作物体而不是斑驳，保持原样：眼镜的鼻托保持实心，镜片的反光保留，很深的痣也保留；
普通的斑驳、痘印和泛红与周围皮肤只差 10–20%，照常磨平。
强度越高，去掉的斑驳尺度越大：强度 100 时可去掉约 93% 的中等斑驳，面部本身的明暗结构仍然保留。
建议合影里的小脸用 30–60，大脸特写可以用到 100。
**柔肤**开关在 **人像** 一节、磨皮滑块下面，磨皮强度大于 0 时才能打开；打开后连更细的肤质纹理（毛孔）也一起柔化，
皮肤更干净，胶片颗粒仍然覆盖在上面。纹理是靠颗粒盖回去的，所以柔肤实际起多大作用，取决于颗粒落到画面上有多粗：
35 mm 且用胶片自身颗粒时全量生效；颗粒更细（中画幅、颗粒滑块调低）则减弱；关闭颗粒时限制在 40%，以 10% 为一档。
这里的颗粒粗细 = 颗粒开关 × 颗粒滑块 × 胶片自身的颗粒量（只有四款黑白胶片各不相同，彩色胶片共用一套颗粒模型）÷ 胶片画幅尺寸（相对 35 mm）。
被限制时，人像面板会在柔肤开关下方注明（例如“按 70% 生效”）。打开柔肤后，改动颗粒、胶片或画幅而使上限变化，会重新冲印一次（约一两秒）；
滑块的小幅调整通常不会。它和磨皮强度一样存进照片设置、可撤销，复制/粘贴设置时不复制。磨皮在胶片之前进行：先处理原始解码画面，
再交给引擎冲印，所以胶片颗粒、光晕和相纸曲线照常落在皮肤上，不会在有颗粒的照片里出现一块光滑的塑料脸。
这是本 fork 唯一的修图例外，其他一律不在冲印后改像素。调整强度需要重新冲印一次，大图约 1–2 秒。
**AI 精修**也可以调整磨皮：有人脸时才用，自然人像一般 0.2–0.4，人物很小或只是背景时不用；
只有在你明确要求干净、柔和或美颜风格的皮肤时，才会打开柔肤；
实测本地 `gemma4:26b` 在“自然的人像肤质”意图下设为 0.3。设置的复制/粘贴不包含磨皮，因为每张照片的人脸不同。
暂不支持半格拼接。

**AI 精修**让模型查看 1024 px 的成片，最多三轮调整测光方式、胶片曝光、相纸亮度、放大机 Y/M 滤色、
预闪、颗粒、光晕、场景置位和显影后调色。它不能修改胶片、相纸、裁剪、片边、日期后背或
解码；越权或越界的修改会被拒绝并反馈给模型。**撤销 AI 修改**可一步恢复 AI 修改前的编辑，
⌘Z 可以撤回这次恢复。它不做生成式修图：只调整已有控件，不改写胶片模型，也不改写成片像素，结果保存在
普通 sidecar 中。暂不支持半格拼接。

只有点击 **推荐胶片**、**推荐构图**或 **开始精修**时才会发送照片，同时发送拍摄参数和调整数值；连接测试
只发送文字请求。费用计入你自己的 API 账户。Key 存在 macOS 钥匙串中，不写入设置、sidecar
或日志。MCP 工具 `compare_stocks` 也可让外部 Claude Code 或 Claude Desktop 比较胶片，
无需应用内 API Key；对应的命令行示例：`spektralab compare photo.NEF --mono --preview sheet.jpg`。
